实时通信架构 — Socket.IO

聊天 + 通知推送，共用一条 WebSocket 连接

连接与消息流

🔌 连接建立

1. 用户登录 → 前端获得 JWT token
▼
2. 建立 WebSocket → Socket.IO 连接，携带 token
▼
3. 服务端验证 → 解析 JWT，将 socket 与 userId 绑定
▼
4. 加入个人房间 → socket.join(`user:${userId}`)
▼
5. 就绪 → 可收发消息、接收通知

💬 聊天消息流

A 发送消息:
emit('send_message', { conversationId, content, receiverId })
▼
服务端处理:
① 存入 messages 表
② 发送给 B: io.to(`user:${receiverId}`).emit('new_message', msg)
▼
B 客户端: 收到 new_message 事件，更新聊天界面

🔔 通知推送流

触发动作
投递成功 / 状态变更 / 新消息
→
服务端
① 写入 notifications 表
② io.to() 推送到目标用户
→
客户端
顶部通知铃铛 🔴红点

前端状态管理设计

Pinia Store 划分
Store 职责 关键状态
useAuthStore 认证与用户信息 token, user, role, isLoggedIn
useChatStore 实时聊天 conversations[], activeChat, messages{}, unreadCount
useNotificationStore 通知管理 notifications[], unreadCount, wsConnected
useApplicationStore 投递管理（求职者+公司方） applications[], statusFilter, stats
