关键设计决策

包含

  • 前端 SPA + 后端 REST API 标准分离
  • JWT Token 无状态认证
  • HTTP 处理普通请求 + WebSocket 处理实时消息/通知
  • PDF 文件本地存储（uploads/ 目录）

不包含

  • Nginx 反向代理（开发环境 Vite proxy 替代）
  • Redis 缓存
  • 消息队列
  • Docker 容器化
